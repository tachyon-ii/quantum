Physics and grades: `SPEC-peel-and-roll.md` (same folder). This document is the *build*: every constant, every functional, every output and its file format, and the acceptance tests. Three implementations that follow it should agree to the mesh-convergence tolerance (§9) or disagree for a reason that can be found in a diff. Correlation or abomination — either is a result.

**Rule R4′ (binding on all three):** the report is generated by the code (`report.md` written by `run_all.py`); no number is typed by hand; Grace re-runs the code from the repo and grades only what reproduces. Any line that does not reproduce is struck, not argued.

## 1. What is being built

A quasi-static continuum model of A nucleons as **inflated capsids with a triangulated, near-inextensible skin**, adhering where their skins are close, with a **graded adhesion well** that is full in contact and fades to zero over a gap δ. Egg-shaped patches, rim deficits, the fat end at the hub, unzipping under load, pivot-egg inversion and rolling are to **emerge** from this functional — none is to be coded in. Prior art to credit: Seifert & Lipowsky 1990 (vesicle adhesion with a contact potential); Kendall 1971 (peel); Helfrich 1973 (bending); Timoshenko for nothing.

## 3. The energy functional

Each capsid i is a closed triangulated surface with vertices **x**_v, rest radius R_i (RP or RN), rest face areas A_f⁰ (from the icosphere scaled to R_i), rest volume V_i⁰ = 4πR_i³/3, rest total area A_i⁰ = 4πR_i². All vertices are free degrees of freedom; capsid "centres" are the vertex centroids (derived, never a DOF).

E_total = Σ_i [E_inflate,i + E_area,i + E_bend,i] + Σ_{i<j} [E_adh,ij + E_pen,ij + E_mesh,ij + E_Coul,ij] + E_sling

1. **Inflation** (soft-capsid P2, γ_V = 1): E_inflate,i = E₀ · (V_i⁰ / V_i − 1), V_i by the divergence theorem over faces. E₀ is calibrated (§4).
2. **Skin area** (near-inextensible): E_area,i = K_AREA · Σ_f (A_f − A_f⁰)² / A_f⁰, with K_AREA = 50 · E₀ / A_i⁰ (declared; check in §9 that doubling it moves no reported number by > 0.5 %).
3. **Bending** (Helfrich discrete): E_bend,i = K_BEND · Σ_edges (1 − cos θ_e), θ_e the dihedral angle; **K_BEND = 0 in the primary run**, K_BEND = 0.01 · E₀ in the variant (both reported).
4. **Graded adhesion** — the whole point. For each vertex v of capsid i and partner j, the gap g_v = signed distance from **x**_v to capsid j's surface (positive outside; computed as distance to the nearest face plane of j among the faces whose centroid is within 3 mean-edge-lengths of v, via a KD-tree on j's face centroids; negative if inside). E_adh,ij = −e₀ · Σ_{v∈i} A_v · s(g_v/δ) − e₀ · Σ_{v∈j} A_v · s(g_v/δ), with A_v = ⅓ Σ_{f∋v} A_f, and the **fade function** s(x) = 1 for x ≤ 0; (1 − x) for 0 < x < 1; 0 for x ≥ 1. Variant (reported): s(x) = (1 − x)² on (0, 1). The factor ½ is *not* applied: each skin is adhered to the other, both sides count, and e₀ is defined per unit area of *one* skin. e₀ is calibrated (§4).
5. **Penetration**: E_pen,ij = K_PEN · Σ_v A_v · max(0, −g_v)², K_PEN = 10 · e₀ / (0.05 RP)² (declared: a 5 % penetration costs ten times the adhesion it would gain).
6. **Lane mesh (shear term, spin-signed)**: E_mesh,ij = E_MESH · [pair ij is singlet], where singlet ⇔ same species (nn, pp) or an np pair declared singlet. E_MESH is set by the np singlet datum in §4.2. It is a per-contact constant, applied only if the pair has any vertex with g_v < δ.
7. **Coulomb**: E_Coul,ij = AHC / |**c**_i − **c**_j| for proton–proton pairs, **c** the vertex centroid.
8. **Slingshot**: E_sling = −A · Y(A), A = number of capsids (Option I, y = A), applied only if the contact graph is connected.

Binding energy reported = −E_total at the relaxed minimum (positive = bound).

## 4. Calibration — exactly this, in this order

4.1 **Relaxation**: L-BFGS-B over all vertex coordinates, gradients analytic or by autodiff (jax or torch; declare which), `gtol 1e-8`, from the starting geometries of §5. Rigid-body drift is removed by pinning the centroid of the whole system.

4.2 **E_MESH** from the deuteron singlet, closed form: with the triplet D relaxed at calibration, E_patch(D) ≡ BE_D − 2Y(2) = 0.788624 MeV; the singlet np at the same geometry must sit at E_SINGLET, so **E_MESH = E_patch(D) − E_SINGLET = 0.854624 MeV.** (Argon's 18 Oct value; reproduced by Grace. The only line of that report that is kept.)

4.3 **e₀ and E₀** from D and ⁴He simultaneously at each δ in DELTA_GRID: solve BE_model(D; e₀, E₀, δ) = BE_D and BE_model(⁴He; e₀, E₀, δ) = BE_HE4 by Newton/Nelder-Mead on (e₀, E₀) with the relaxation inside the loop. Report (e₀, E₀) for every δ. **δ is not fitted**: all four rows go in the report; the physics spec's prediction is that the egg orientation and the per-bond ordering are δ-independent and the T/³He numbers vary slowly.

Nothing else is tuned. If a constant has to be introduced to make the minimiser converge, it goes in `constants.py` with a comment and in the report's "undeclared at spec time" table, and the run is flagged amber.

## 5. Geometries and the measured-distance rule

Starting centres (fm; relaxed freely afterwards): D: p (0,0,0), n (1.70,0,0). T: p (0,0,0), n (1.70,0,0), n (0.85, 1.47, 0). ³He: p, p, n likewise. ⁴He: regular tetrahedron of edge 1.70, p,p,n,n with the pp pair on one edge. Species radii RP/RN. **Contact distances are what the relaxation produces.** The rms centroid distances unfolded from charge radii (D 3.91, T 2.676, ³He 3.078, ⁴He 2.371 fm) are *quantum averages* and are **never used as inputs**; they appear only in `compare.py` as targets for the radii outputs (§7.1), and the report must state that a classical minimum underestimates them. Using them as contact distances is the 16 Oct "mixed distances" error and fails the build.

## 6. Load paths (quasi-static, force-controlled) — on T and ³He

For each path, apply an external force **F** to all vertices of P1 (uniformly by area), hold the system centroid pinned, relax, increase |F| in steps of 0.02 MeV/fm from 0, and at each step record: E_total, the contact map of every pair (per-vertex s(g_v/δ) > 0), the patch area and the well-weighted centroid of each patch, the positions of all three centroids. **Snap** = the first step at which relaxation fails to find a minimum with all three pairs still in contact (saddle-node) — report the force F_snap and the geometry of the last stable step. Paths: **tangential** (perpendicular to P1's centroid-to-hub radial, in the plane, toward P3), **radial outward**, **out-of-plane**. P1 is the proton in T (and one proton in ³He, with the pp pair as P1–P2 in one run and as P1–P3 in another — four ³He runs in total; two for T, kicking the proton toward each neutron is one by symmetry, plus kicking a neutron toward the proton).

## 7. Required outputs (all written to `results/<nucleus>.json` and `report.md`)

7.1 **Energies and radii**: BE for D, T, ³He, ⁴He at every δ; per-bond energy after slingshot and Coulomb; relaxed centroid distances; rms charge radius from the proton centroids plus RP in quadrature (state the classical caveat). *(Physics spec outputs 1, 6.)*
7.2 **Patch geometry** per pair: area; perimeter; well-weighted centroid vs geometric centroid; principal axes of the energy-weighted distribution; **aspect ratio**; the sign of (well centroid − geometric centroid)·(hub direction) — positive means fat end at the hub. For T and ³He also the fraction of the patch energy in the hub half. *(Output 2; the §4.3 ruling check and P3.)*
7.3 **Quartic mode**: displace P1's centroid out of plane by z ∈ {0, ±0.05, ±0.10, ±0.20, ±0.30} fm (rigid shift of its vertices, then relax everything else), fit E(z) = E₀ + k₂z² + k₄z⁴, report k₂ (should be ≈ 0 for a distance-only energy; a non-zero k₂ measures the mesh/non-central content), k₄, and the 1-D Schrödinger ground state for reduced mass (2/3)·(MP+MN)/2 in that potential: E_zp and p_rms. *(Output 3.)*
7.4 **Peel**: from the contact map, the local line-energy e₀·s × front width at the point, at the broadside, and at the hub end of each patch; **F_snap** for the three load paths and their ratios. *(Output 4.)*
7.5 **Roll**: along the tangential path, the angle rolled by P1 about P3's centroid at the last stable step = **θ_snap**; the P2–P3 well-centroid trajectory (does its fat end move outward? when, relative to the P1–P2 unzip fraction?); the P1–P3 well-centroid trajectory (**inversion** = sign change of 7.2's quantity; the force at which it happens = inversion load); whether the two inversions are simultaneous or sequential, defined as |ΔF| between them < 2 steps. *(Outputs 5, 8.)* The D's bond-axis angle to P1's velocity at snap → β_D. The sign of t₂₀ is **not** to be reported by the code — only β_D; the mapping to t₂₀ is a physics question Grace grades.
7.6 **Spin of P1** along the tangential path: rotation of P1's vertex set about its centroid relative to its initial orientation (Kabsch), reported as an angle and axis at snap. *(Output 9.)*
7.7 **Chain**: place P1–P3–P2 collinear at contact distances, relax with P3's centroid pinned; report the energy relative to D + N and the saddle (if any) along the P1 separation coordinate. *(Output 7.)*

## 8. File layout (identical across the three implementations)

```
models/binding/membrane/
  constants.py   targets.py   mesh.py (icosphere, areas, volume, dihedrals, KD-tree gaps)
  energy.py (§3)   relax.py (§4.1)   calibrate.py (§4.2–4.3)   paths.py (§6)
  analyse.py (§7.2–7.6)   chain.py (§7.7)   run_all.py (runs everything, writes results/*.json and report.md)
  compare.py (imports targets.py; appends the comparison table to report.md)   results/
```
`run_all.py` asserts that `targets` is not in `sys.modules` until `compare` is invoked. Every file carries the implementer's name and model in line 2. Total runtime target: under 30 minutes on a laptop at SUBDIV 3; if it is not, reduce DELTA_GRID to two values and say so.

## 9. Acceptance tests (`tests/`, run by `run_all.py` first; a failure stops the run)

1. An isolated capsid relaxes to a sphere: |V − V⁰|/V⁰ < 10⁻⁴, E_total < 10⁻⁶ E₀.
2. Two capsids pushed together and released at the calibrated (e₀, E₀, δ) find a minimum with a patch; E(d) has a single minimum; the patch is a disc (aspect ratio 1 ± 0.02).
3. D and ⁴He reproduce their calibration targets to 10⁻⁴ MeV (by construction; a check that the fit converged).
4. T's two np patches are identical by symmetry to 0.5 %.
5. Mesh convergence: BE(D) and BE(T) at SUBDIV 4 within 1 % of SUBDIV 3; otherwise report at SUBDIV 4.
6. K_AREA doubled: no reported number moves by > 0.5 %.
7. Rotational invariance: a rotated starting geometry gives the same BE to 10⁻⁴.

## 10. What a passing report looks like

A `report.md` generated by code, beginning with the constants table and the git hash, then §7.1–7.7 as tables, then the §9 test results, then — last — `compare.py`'s table against `targets.py`. No prose claims of "confirmed". No grades: the grading is Grace's. Any constant not in this document that the implementer had to add is in an "added" table at the top, so the three implementations can be diffed at a glance.

## 11. What would make it an abomination

Rms distances used as contact distances; a well shape or crease factor that depends on which nucleus is being computed; `targets` imported anywhere but `compare.py`; any number in the report that `run_all.py` did not write; a "snap" or "sequential" asserted rather than found by the load path; a quartic mode taken from a stiffness constant instead of from E(z); a t₂₀ sign in the code.
