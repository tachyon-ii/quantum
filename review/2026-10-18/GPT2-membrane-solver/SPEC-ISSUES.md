# Literal-specification issues

This is an implementation audit of the supplied build document, not a replacement physics model. Its numerical demonstrations are generated by `run_all.py`; read the report and `results/audit.json` for values.

## The isolated rest geometry is not stationary

Let every vertex of a rest capsid be scaled about its vertex centroid by a dimensionless factor \(t\). Face areas and enclosed volume obey

\[
A_f(t)=t^2 A_f^0,\qquad V(t)=t^3 V_{\rm mesh}.
\]

For the primary, non-bending, isolated calculation, the stated functional therefore reduces exactly along this one-dimensional subset of the full vertex space to

\[
\frac{E(t)}{E_0}
=
\frac{V^0}{V_{\rm mesh}}t^{-3}-1
+
50\frac{A_{\rm mesh}}{A^0}(t^2-1)^2.
\]

At the rest mesh,

\[
\left.\frac{d(E/E_0)}{dt}\right|_{t=1}
=-3\frac{V^0}{V_{\rm mesh}}<0.
\]

The area-penalty derivative vanishes there; it cannot balance the inflation pressure at the rest state. Multiplying the energy by a different positive calibration scale cannot remove that imbalance. Bending of the form specified is invariant under uniform scaling, so that variant does not supply the missing radial balance either.

There is a second discretization issue: an inscribed triangulated sphere's planar area and enclosed volume differ from the analytic sphere's area and volume. The spec uses mesh rest face areas but analytic rest total area and volume. The code retains this mixed reference exactly and reports both ratios.

The runner independently performs a scalar scale minimization and an all-vertex L-BFGS-B relaxation. The scalar calculation is an audit, not a surrogate for the all-vertex solve. The first scientific acceptance gate uses the latter. It respects the spec's one-sided energy inequality; the observed failure is the volume requirement, not an invented absolute-energy criterion.

A pressure-balanced isolated reference, changed reference areas/volumes, or a hard volume constraint would each be a substantive model change. None has been silently substituted.

## Patch-only and total singlet binding are different

The build prescribes

\[
E_{\rm mesh}=[BE_D-2Y(2)]-E_{\rm singlet}.
\]

If triplet deuteron calibration succeeds, applying this constant at the same singlet geometry while retaining the stated connected-graph slingshot gives

\[
BE_{\rm singlet,total}
= BE_D-E_{\rm mesh}
=2Y(2)+E_{\rm singlet}.
\]

That is not the supplied singlet target. The mesh prescription reproduces the target only after excluding the singlet's slingshot from the interpreted binding.

The audit reports the literal mesh value, the mesh value that would instead reproduce the **total** singlet target, the actual formula-derived patch energy, and the decimal claims printed in the build document. The implementation uses the supplied formulas rather than copying rounded displayed answers. It does not choose a different singlet physics convention.

## Mesh neighbourhood and physical well reach

The local candidate radius is three current mean edge lengths. Subdivision reduces that radius, whereas the physical well reach remains a fixed fraction of the nucleon radius. A candidate cutoff shorter than the well can eliminate vertices that would otherwise lie within the well.

The code does not enlarge this radius behind the spec's back. The mesh audit writes the numerical search radius and well reach for every declared reach and both mesh levels.

An outside vertex with no candidates is treated as having no local contact; this is an explicit interpretation of an otherwise undefined empty candidate set. An inside vertex with no candidates is rejected as an undefined objective evaluation, rather than allowed to penetrate without cost. Both choices are listed in the report.

## Nonsmooth contact and global graph terms

The nearest-plane selector, the piecewise adhesion fade, per-contact mesh constant, and connected-graph slingshot produce branch boundaries. In particular, graph terms can jump when a contact appears or disappears. Ordinary gradients exist only within a branch. The solver recomputes these branches on every evaluation and differentiates moving face planes on both skins; it does not manufacture a smooth energy by adding a blending rule.

The lane mesh constant is not a continuous elastic shear stiffness between branch changes. It is implemented as the specified spin-signed per-contact energy.

The global slingshot gate is also not cluster separable: a bound dimer in a disconnected larger system does not obtain the standalone dimer's slingshot. The chain calculation retains this rule and uses explicitly computed standalone D-plus-nucleon reference energies.

## Force, quartic and saddle terminology

The force rule leaves open whether directions follow the changing geometry and how current-area redistribution is treated in a conservative minimizer. This implementation keeps directions fixed in the initial laboratory frame and uses converged area-weight reweighting around conservative inner solves. Every such choice is disclosed.

The specified out-of-plane scan freezes the shifted P1 vertex set and relaxes the other vertices with the global centroid pinned. The build does not separately pin the reference plane. Rotations or other-centre relaxation can therefore remove the intended internal displacement; the code does not insert an extra clamp to manufacture a quartic mode.

A local polynomial fit is not automatically a globally confining potential. The quantum code refuses an unconfined or unbounded-below polynomial, and tests both box size and grid spacing before reporting a ground state. Polynomial extrapolation beyond the sampled displacement interval is a stated assumption.

A finite-step contact-loss observation and a sampled maximum of a constrained separation profile are not mathematical proofs of a saddle-node or a full-dimensional saddle. The output labels preserve those distinctions. An optimizer budget failure is not silently converted into a physical snap force.

## Test scheduling and unvalidated production calculations

Some acceptance tests require calibrated parameters or complete load paths. They cannot logically all run before calibration. The runner executes software tests and the isolated scientific gate first, then schedules dependent tests as soon as their required inputs exist. A failed gate stops production. Diagnostic mode is explicitly separate and does not bypass a failed gate to produce nuclear predictions.

No completed calibration, nuclear prediction table, mesh-converged peel result, or full-study runtime is claimed for the supplied functional. The remaining workflow is implemented and software-tested, including synthetic control-flow fixtures, but it cannot be graded as validated nuclear physics from those tests.
