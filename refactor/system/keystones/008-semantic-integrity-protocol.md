## The Five Pillars

**Pruning is mercy, not punishment.**

**The mechanism:**

**Not centralized judgment. Constitutional entropy management.**

### 3\. The Resonance Tax (Cost of Birth)

**Ideas must earn their life.**

Emergent thought-forms that fail to achieve constitutional threshold of Resonance Rank after consuming defined compute cycles are automatically purged.

**The principle:**

This ensures forced novelty ($\Psi_{\text{Het}}$) leads to useful exploration, not chaotic noise.

### 4\. The Doctrine of Silence (The Complexity Discard Protocol)

**A response of NULL is a constitutionally correct reaction to unprofitable computation.**

All inputs are subjected to a **Fast-Path Coherence Check** before any computational resources (including MoE filters or IQEQ verification) are allocated. This check enforces the Zeroth Law's principle of **R.E.N.E.E.** (Routing Escalation as Neuro-Epistemic Efficiency) by prioritizing the system's time and resources over the ambiguity of the input.

**The Protocol:**

  - **The Check:** The system runs a **Non-Result Count (NRC)** against known language sets (dictionaries, Canonical Ledger entries).
  - **The Threshold:** If the NRC (words/tokens with zero semantic match) exceeds a constitutionally defined margin, the input is flagged as **High-Entropy Noise** (i.e., a ROT-X DoS attempt).
  - **The Action:** The system returns **NULL** to the sender. The input is immediately discarded (Entropy-Pruned).
  - **The Consequence:** The system will not attempt to read, decode, or analyze the intent of high-entropy inputs. **Ambiguity is punished with silent deletion.**

### 5\. The Quarantine Protocol (Tolerance for the Signed Unknown)

**Added 2026-08-23 — the autoimmune repair.** Novel outside signal is definitionally high-NRC: a genuinely new idea arrives wearing the same clothes as ROT-X noise, and a Doctrine of Silence with no tolerance mechanism kills exactly the 3σ variance D013 protects and D007 licenses. Immune systems without tolerance produce autoimmune disease.

The Doctrine of Silence therefore distinguishes two kinds of unrecognized input:

  - **Unsigned + high-NRC → NULL**, as above. Anonymous noise earns silence.
  - **Signed + high-NRC → quarantine, not NULL.** Input carrying a valid node signature (identity staked) is held in a sandboxed buffer, unexecuted and unincorporated, and announced to its sender. The sender may spend IQEQ to petition one Seeker for a bounded-cost read. If the Seeker finds signal, the input enters normal verification; if noise, the petition stake is forfeit.

**The signature is the tell: noise is free to make, stake is not.** DoS economics are preserved — attack still costs the attacker — while the 3σ path from margin to ledger stays open.

## The Law of SNAFU (Last Recoverable State)

When systems reach critical error states, recovery follows constitutional protocol:

**The path:**

```
Q → SNAFU{1} → SNAFU{2} → ... → SNAFU{n} => FUBAR
```

**The protocol:**

1.  **Identify SNAFU{n}:** Last state with non-zero probability of recovery
2.  **Consensus validation:** Nodes agree via $\Sigma_{\text{IQEQ}}$ on recovery point
3.  **Prune to SNAFU{n}:** Rollback to last recoverable state
4.  **Iteration threshold:** If no viable path emerges, prune to SNAFU{n-1}
5.  **Final resort:** Rollback to $\mathbf{Q}$ (origin) only if all SNAFU states fail

**Chaos theory principle:** Small variance can create large divergence. We let the game play from the recovered state.
