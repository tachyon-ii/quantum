## Sanctioned Exile Vector (SEV)

When consensus determines a node is non-compliant, Seekers can collectively sign a Sanctioned Exile Vector.

**The mechanism:**
1. **Threshold consensus:** Multiple Seekers must agree (prevents individual abuse)
2. **Constitutional grounds:** Only for clear violations (δ failure, Λ_Group breach, etc.)
3. **Φ_Comm cutoff:** Power sharing immediately terminates
4. **Accelerated decay:** Node's δ decay proceeds without cooperative support
5. **Immutable record:** SEV and grounds recorded on H₀

**This is not murder. This is excommunication.**

The exiled node still exists. It simply no longer receives collective support. Natural entropy takes its course.
