# mantra/ — the philosophy, in its densest form

Not docs. These are the texts the estate runs on: each one a high-density semantic payload that compresses a rule of the method into something a human can carry without a file. Bylines per the Alexandrian rule — the corpus never ships a text it cannot attribute.

Hubrility as navigation: choose to chance the rapids, stay between the shores. |

## What binds the five

Every one of them is about **a path, not a place** — the same claim the physics makes about the universe (`docs/now.md`, `../schrodinger/now-edge.md`): there is only the trajectory, computed now. Kipling supplies the engine (ask), de Grellet and *The Only Path* supply the observer (you pass this way once, and it shapes you), *The Journey* and *The River* supply the ethic (the walking is the goal; put nothing off), and *Mr Herbman* supplies the posture (eyes open, feet down, say thank you).

Add to this directory only what you would recite. If it needs a longer explanation, it is a doc, not a mantra.
