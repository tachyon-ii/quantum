## 1) The Geometric Assembly Model

### 1.1 Fundamental Components

Using our formal nomenclature:
- **s** (simplex): Single triangular unit, Order 0
- **S** (Simplex-Prime): Order 1 Sierpinski face (3 s units)
- **SLs/SRs**: S with left/right attached s flap for folding

### 1.2 Assembly Statistics

When three U-units (S + s flap) attempt to form a quark:

**Success Rate: 2/8 = 25%**
- (L,L,L) → Successful quark
- (R,R,R) → Successful quark

**Failure Rate: 6/8 = 75%**
- (L,L,R), (L,R,L), (R,L,L) → Mixed chirality, geometric lock
- (L,R,R), (R,L,R), (R,R,L) → Mixed chirality, geometric lock

These failed assemblies **cannot unfold** (energy barrier) or **complete** (geometric impossibility). They remain frozen in frustrated configurations = **dark matter**.

### 1.3 The Hexagon Trap

A competing stable attractor:
- **(S)₆ · n·s** for n=0..12
- **n=0**: Perfect hexagon, can tile infinitely → dark matter sheets
- **n≥1**: Disrupted geometry, cannot tile → fragments or polymers

The universe is saved from complete crystallization only because P(n=0) << P(n≥1).

- Mixed chirality assemblies: (L,L,R), (L,R,L), etc.

- 3-S triads (most common fragments from hexagon fracture)
- Orphan S and s units

- Distribution: Diffuse background

## 4) Observational Consequences & Falsifiers

### 4.1 Gravitational Signatures

**Prediction:** Three distinct dark matter populations with different distributions:
- **Clumpy** (frustrated assemblies) → NFW-like profiles
- **Filamentary** (hexagon polymers) → Cosmic web structure
- **Diffuse** (debris) → Smooth background

**Falsifier:** Uniform, single-component dark matter distribution

**Quantitative test:** Multi-component fits to lensing data should show:
- Component 1: ρ ∝ r^(-1) core (frustrated assemblies)
- Component 2: Filamentary structure at >5σ significance
- Component 3: Constant background at ~10% of peak density

### 4.2 Self-Interaction Cross-Section

**Prediction:** Variable by component:
- Frustrated assemblies: σ/m ≈ 0.01 cm²/g (nearly collisionless)
- Hexagon polymers: σ/m ≈ 0.1 cm²/g (weak self-interaction)
- Debris: σ/m < 0.001 cm²/g (collisionless)

**Falsifier:** Uniform self-interaction across all scales

**Test:** Bullet Cluster-like mergers should show component separation

### 4.3 Annihilation Signatures

**Prediction:** Residual 511 keV from rare matter-antimatter contacts in dense regions
- Rate ∝ ρ² in galaxy centers
- Stronger in younger systems (less settled)
- Absent in void regions

**Falsifier:** No 511 keV correlation with dark matter density

**Quantitative threshold:** 511 keV luminosity L ∝ M_DM^2/R³ with coefficient matching assembly model

### 4.4 Small-Scale Structure

**Prediction:** Geometric assembly creates characteristic scales:
- Minimum halo mass: ~10^6 M_☉ (single frustrated assembly cluster)
- Preferred filament width: ~1 Mpc (polymerization length scale)
- Core radius: ~1 kpc (geometric packing limit)

**Falsifier:** Scale-free dark matter distribution

### 4.5 Cosmic Web Topology

**Prediction:** Filaments show discrete branching with up to 6 connections per node (hexagon vertices)

**Falsifier:** Random or non-geometric branching patterns

**Test:** Topology analysis of large-scale structure should show:
